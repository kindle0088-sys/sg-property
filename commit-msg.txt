fix(psf): honest 1yr PSF labels + MAD outlier rejection

P0 — label honesty: 2468 projects (19%) have no transactions in the 1y
window; their avgPsf1y is 0 and the UI was showing all-time avg PSF under
the "1yr Avg PSF" label (e.g. Blk 346 shows $72 - a real 1990 sale price,
not a 1-year figure). Added utils.psfText/psfLabel; all views now label
"1yr PSF" only when avgPsf1y exists, otherwise "Avg PSF (all)".

P1 — outlier rejection: computeAvg1y now drops PSF outliers beyond
median +- 3 * 1.4826 * MAD before averaging (skipped for <5 samples),
protecting against single bad floor-area records skewing the number.
758 projects changed vs previous build.

Build pipeline fix: --skip-ura/--skip-hdb builds never recomputed
avgPsf1y (committed index stats were reused verbatim). Added
loadCommittedTxns() which reads per-project detail JSONs (cached) so
skip builds recompute with MAD too. HDB detail files store sortDate
(yyyy-mm) not month; normalized back to month for computeAvg1y.

Also remove stray commit-msg.txt that got committed in 8f46ac887.
